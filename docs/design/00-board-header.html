Un portafolio que se comporta como el estado de Vue: cada gesto del visitante —mover el cursor, hacer scroll, hacer clic— es una mutación, y la interfaz reacciona. Tipografía gigante que se estira, color que cambia por módulo y transiciones que «recompilan» la página.

Tinta#0E0E0C · fondo base

Cobalto#2E3BFF · plano técnico
Grafito#17171A

Regla: un solo acento por pantalla. Ceniza solo sobre tinta/grafito; sobre hueso usar #5E5B54.

(C) Principios
01
Reacción, no decoración

Cada efecto responde a algo que hizo el visitante. Nada se mueve «porque sí».

02
La tipografía es la imagen

Titulares de borde a borde; el eje de ancho de Archivo es el material que se anima.

03
Un módulo, una atmósfera

El fondo cambia de color al cambiar de sección; el scroll se siente como pasar de sala.

04
Rápido y accesible

Curva expo.out, 600–900 ms. Con prefers-reduced-motion todo pasa a fundidos de 200 ms.
